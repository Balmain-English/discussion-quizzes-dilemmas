Individual player mode

1. Set up your quiz

Leave blank to use your selected category. Be specific for more focused quizzes.

Built-in questions work offline. AI generation requires an API key and an internet connection.

2. How to play

  1. Choose your English level and quiz settings.
  2. Answer each question before moving on.
  3. Read the explanation and language note after each answer.
  4. Collect points and check your final score.
  5. Review the questions you missed and try again.
Designed for language learningQuestions use clear, level-appropriate English. Explanations provide context and useful vocabulary, not just the correct answer.
AI settings and API key
If you run the included proxy, enter its address. The key then stays on the server and the key field can be left empty.

Security: the key is held only in this page's memory and is not saved to storage or included in the downloaded file. It is sent in a request header, not in the web address. A browser-based request still exposes the key to your browser session and network environment, so for shared or classroom use, set up the included proxy and enter its URL above.
