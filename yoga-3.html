Sixty-item question bank across six domains. Each attempt presents a random sample of twenty questions. Select one answer per item.

Assessment protocol

Questions are sampled without replacement for each attempt using the Fisher–Yates shuffle. The sample is drawn from the complete question bank; category proportions are therefore not guaranteed in an individual attempt.
